# Assembly Practice

This repository contains my assembly language exercises and practice code.  
It is part of my learning journey in computer architecture & organization in Year-2 of KMITL.

## 📂 Structure
- `codes/` → Assembly source files (.asm)
- `build/` → Build files, object files
- `Makefile` → Build automation for assembling & linking

## 🚀 Getting Started
To assemble and run the programs:
make FILE=n01
make run FILE=n01

To remove the build folder:
make clean
